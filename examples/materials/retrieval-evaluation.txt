Проверка качества поиска учебных материалов

Демонстрационный учебный материал проекта Semantic Study Search.

Чтобы оценить поиск, заранее составляют вопросы и отмечают источники, в которых
есть полезная информация. Проверочные вопросы должны охватывать разные темы и
формулировки. Для более надёжной оценки нужен отдельный набор вопросов, который
не использовали при подборе модели и параметров разбиения текста.

В этом проекте Hit@k означает долю вопросов, для которых хотя бы один из первых
k найденных фрагментов принадлежит ожидаемому документу. Например, если нужный
источник попал в первую пятёрку для восьми вопросов из десяти, Hit@5 равен 0,8.
При этом несколько фрагментов могут принадлежать одному документу.

Наличие ожидаемого документа в выдаче ещё не доказывает, что конкретный фрагмент
полностью отвечает на вопрос. Поэтому полезно отдельно оценивать содержимое
фрагментов, их контекст и удобство перехода к исходному материалу.

В набор проверки также включают вопросы, на которые библиотека не отвечает.
Поиск ближайших векторов всё равно может вернуть результаты для такого вопроса.
Значение косинусного сходства само по себе не является уверенностью в наличии
ответа, а порог отсеивания нужно выбирать по отдельным проверочным данным.
