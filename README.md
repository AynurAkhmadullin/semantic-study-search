# Semantic Study Search

Семантический поиск по материалам на основе предобученной модели
[`intfloat/multilingual-e5-small`](https://huggingface.co/intfloat/multilingual-e5-small).
Проект для проектного практикума магистратуры «Инженерия искусственного интеллекта».

Пользователь загружает материалы через Streamlit. Приложение извлекает текст,
разбивает его на фрагменты, вычисляет векторы и сохраняет библиотеку на диск.
После завершения обработки материал сразу доступен для поиска без перезапуска
API и ручного обновления страницы. JSON со списком материалов заполнять не нужно.

Пользователи задают вопросы через веб-интерфейс или FastAPI и получают близкие
по смыслу фрагменты с названием документа. Оригиналы загруженных файлов можно
скачать или удалить. Загрузка, история, поиск, скачивание и удаление материалов общей библиотеки
доступны всем пользователям приложения без авторизации.

При поиске вычисляется только вектор вопроса. Добавление файла не пересчитывает
векторы прежних документов и не обучает модель. Неудачная обработка сохраняет
прежнюю библиотеку. Файлы, состояние загрузок и индекс сохраняются между запусками.

Слабые совпадения отбрасываются по порогу сходства. Начальный порог требует проверки
на материалах пользователя и не гарантирует наличие ответа в произвольном материале.
Если по новой теме ничего не находится, можно включить «Показать и менее точные
совпадения». В этом режиме выдача может содержать неподходящие фрагменты.
Сходство не является вероятностью правильного ответа.

Новая установка начинает с пустой библиотеки. Готовых материалов и вопросов
в приложении нет. Поиск становится доступен после успешной обработки первого
загруженного файла и выполняется только по добавленным пользователями материалам.

## Требования

- Git и [uv](https://docs.astral.sh/uv/getting-started/installation/) версии `0.11.29` или новее.
- Python **3.13**; uv устанавливает его по файлу `.python-version`.
- Windows x86-64 или Linux x86-64; модель работает на CPU.
- Доступ к GitHub, PyPI и `download.pytorch.org` для установки зависимостей.
- Доступ к Hugging Face при первом скачивании модели; веса занимают около 471 МБ.
- Постоянный диск для библиотеки и оригиналов, в том числе при размещении в облаке.

Поддерживаются TXT и Markdown в UTF-8, PDF с текстовым слоем: один файл до **20 МБ**,
до 300 страниц PDF, до 1 000 000 символов текста и до 1000 поисковых фрагментов.
PDF под паролем и полностью нетекстовые PDF отклоняются. Пустые страницы пропускаются
с предупреждением; OCR не выполняется.

Один процесс API обрабатывает один материал за раз. Во время вычисления векторов
поиск может сообщать о занятости; состояние загрузки остаётся доступным.
Для одного каталога библиотеки запускайте один API worker: блокировка защищает
индекс от одновременной записи несколькими процессами API.

## Инструкция установки

```shell
git clone https://github.com/AynurAkhmadullin/semantic-study-search.git
cd semantic-study-search
uv sync --locked --all-extras
```

Для локального запуска API и интерфейса выполните команду из корня репозитория:

```shell
uv run --locked --all-extras semantic-study-start
```

Команда использует кэш модели `.cache/huggingface/hub`, запускает API и ждёт его готовности, затем
запускает Streamlit. Оба сервиса выводят сообщения в один терминал и останавливаются
одним нажатием `Ctrl+C`.

Первый запуск может занять несколько минут из-за скачивания модели. Когда веса
уже скачаны, можно запускать без сети:

```shell
uv run --locked --all-extras semantic-study-start --offline
```

По умолчанию приложение доступно на [порту 8501](http://127.0.0.1:8501),
API — на [порту 8000](http://127.0.0.1:8000/docs). Другие порты можно задать так:

```shell
uv run --locked --all-extras semantic-study-start --api-port 8001 --ui-port 8502
```

Существующие настройки API из окружения сохраняются, включая `SSS_INDEX_DIR`
и `SSS_MODEL_CACHE`. Адрес API для Streamlit единая команда задаёт
автоматически по `--api-port`.

<details>
<summary>Раздельный запуск API и интерфейса</summary>

При необходимости сервисы можно запускать отдельно в двух терминалах.
В первом запустите API. Команды для PowerShell:

```powershell
$env:SSS_MODEL_CACHE = "$PWD/.cache/huggingface/hub"
$env:SSS_OFFLINE = "0"
uv run --locked --all-extras uvicorn semantic_study_search.api.app:app --host 127.0.0.1 --port 8000
```

Первый запуск скачивает закреплённую ревизию E5
`614241f622f53c4eeff9890bdc4f31cfecc418b3`. После скачивания можно установить
`SSS_OFFLINE=1` для работы без сети. Дождитесь `Application startup complete`
и статуса `ready` на [странице состояния](http://127.0.0.1:8000/health).
Отсутствие индекса при первой установке допустимо: API создаёт пустую библиотеку.

Во втором терминале запустите интерфейс:

```powershell
$env:SSS_API_URL = "http://127.0.0.1:8000"
uv run --locked --all-extras streamlit run src/semantic_study_search/ui/app.py --server.address 127.0.0.1 --server.port 8501
```

</details>

Откройте [приложение](http://127.0.0.1:8501):

1. Раскройте «Добавить материал».
2. Выберите файл; при желании задайте название. Нажмите «Загрузить материал».
3. Дождитесь сообщения «готов к поиску»; этапы обработки обновляются автоматически.
4. Введите вопрос и нажмите «Найти». Оригинал доступен через «Скачать материал».

Во время подготовки можно закрыть страницу: обработка продолжается на сервере.
После возвращения нажмите «Загрузки», чтобы увидеть результат
или продолжить наблюдение. Повторная загрузка того же файла не создаёт дубликат.
Если сервер остановился до сохранения индекса, незавершённая задача получит ошибку;
файл можно загрузить повторно.

Для удаления откройте «Добавить материал» → «Загрузки», нажмите
«Удалить материал» у нужного файла и подтвердите действие кнопкой «Удалить окончательно».
Удаляются оригинал, запись в истории и все поисковые фрагменты этого файла для всех
пользователей. Остальные материалы остаются доступны; их векторы не пересчитываются.
После удаления последнего файла поиск отключается до новой загрузки. Удалённый файл
можно загрузить заново. Во время обработки другого материала удаление недоступно.

Оригиналы и метаданные загрузок по умолчанию находятся в
`data/processed/library/uploads/<id>/`. Тексты и векторы — в SQLite и `vectors.npy`
в каталогах версий индекса. `CURRENT` указывает на готовую версию. Не изменяйте
эти файлы вручную. Для резервного копирования сохраняйте весь каталог библиотеки
и отдельный каталог оригиналов, если задан `SSS_UPLOAD_DIR`.
При удалении материала прежние версии индекса очищаются, чтобы не хранить его тексты
и векторы. Прерванное удаление завершается при следующем запуске API.

Streamlit обращается к API по HTTP и не загружает модель. Оба процесса
останавливаются через `Ctrl+C`. Загруженные материалы остаются на диске.

Переменные задаются перед запуском соответствующего процесса:

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `SSS_INDEX_DIR` | `data/processed/library` | Каталог библиотеки, относительно рабочей папки API |
| `SSS_UPLOAD_DIR` | `<SSS_INDEX_DIR>/uploads` | Оригиналы и состояния загрузок |
| `SSS_MODEL_CACHE` | Стандартный кэш Hugging Face | Каталог весов модели |
| `SSS_OFFLINE` | `0` | `1` или `true` — только локальные веса; `0` или `false` — разрешить скачивание |
| `SSS_MIN_SCORE` | Около `0.82066` | Порог сходства от -1 до 1; `-1` отключает фильтр |
| `SSS_API_URL` | `http://127.0.0.1:8000` | Адрес API для процесса Streamlit |

`.env` автоматически не читается. В Bash используйте `export ИМЯ="значение"`.
Для новой библиотеки порог необходимо оценивать отдельно. Изменение настроек
окружения требует перезапуска соответствующего процесса; загрузка файлов через UI — нет.

API описан в [Swagger](http://127.0.0.1:8000/docs):

| Метод | Путь | Назначение |
| --- | --- | --- |
| `GET` | `/health` | Готовность и размер библиотеки |
| `POST` | `/search` | Поиск по вопросу |
| `POST` | `/materials` | Multipart: `file` и необязательный `title`; возвращает HTTP 202 и идентификатор |
| `GET` | `/materials` | История загрузок общей библиотеки |
| `GET` | `/materials/{id}` | Состояние обработки |
| `DELETE` | `/materials/{id}` | Удаление файла и его фрагментов; успешный ответ HTTP 204 |
| `GET` | `/materials/{id}/file` | Оригинал опубликованного материала |

Методы API доступны без авторизации. Оригиналы доступны только после индексации.
Удаление неизвестного или уже удалённого материала возвращает HTTP 404.

Вопрос — от 1 до 2000 символов и не более 512 токенов с префиксом модели.
`top_k` — целое число от 1 до 20; по умолчанию 5. `relaxed=true` включает
совпадения ниже порога. Если в загруженных материалах нет близких фрагментов,
возвращается HTTP 200 с `results: []`. Пока библиотека пуста, поиск возвращает
HTTP 409 с просьбой сначала добавить материал; кнопка поиска в UI отключена.
Ошибки ввода возвращают 422, занятая обработка другого файла — 409, превышение размера — 413,
временная недоступность или занятость модели — 503.

Дополнительная команда `semantic-study-index` принимает только явно указанные
пользовательские источники: `--manifest` со списком своих TXT/MD/PDF или `--corpus`
со своим JSON-корпусом. Без источников команда завершается с сообщением об ошибке.
Параметры можно повторять; пути материалов в списке отсчитываются от JSON-файла.
CLI задаёт **полный состав** библиотеки, поэтому запускайте его при остановленном
API и только если намерены заменить состав индекса. Для добавления отдельных
файлов в существующую библиотеку используйте UI.
Размер фрагмента задаётся через `--chunk-tokens`, перекрытие — `--overlap`
(по умолчанию 320 и 48 токенов). `--force` принудительно пересобирает индекс.

Команда `semantic-study-search` принимает свой вопрос для поиска по сохранённой
библиотеке. `--json` включает JSON-вывод; `--min-score` меняет порог;
`--index-dir` задаёт каталог индекса. Полная справка доступна через `--help`.

## Зависимости

| Группа | Состав | Назначение |
| --- | --- | --- |
| `ml` | NumPy, Sentence Transformers, PyTorch, pypdf, markdown-it-py | Модель, поиск и извлечение текста |
| `api` | FastAPI, Pydantic, Uvicorn, python-multipart, filelock | HTTP, загрузка файлов и блокировка записи |
| `ui` | Streamlit, HTTPX, Pydantic | Интерфейс, HTTP-клиент и проверка ответов |
| `dev` | pytest, pytest-cov, HTTPX, Ruff | Тесты и проверка кода |

SQLite входит в стандартную библиотеку Python. PyTorch для Windows и Linux
устанавливается из официального CPU-индекса без CUDA. Зависимости описаны
в `pyproject.toml`, точные версии и хеши — в `uv.lock`.

Для разработки используйте `uv sync --locked --all-extras` и
`uv run --locked --all-extras ...`. `dev` устанавливается по умолчанию.
При раздельном размещении компонентов:

```shell
# API и модель
uv sync --locked --extra ml --extra api --no-dev

# Только интерфейс, в отдельном окружении
uv sync --locked --extra ui --no-dev
```

│   ├── evaluation.py        # Контрольные наборы и метрики
│   ├── limits.py            # Ограничения поискового запроса
│   ├── sources.py           # Проверка ссылок на загруженные оригиналы
│   ├── ingestion/           # Импорт, очистка и разбиение текста
│   ├── search/              # E5, ранжирование и фильтрация
│   ├── storage/             # SQLite, NumPy и версии индекса
│   ├── api/
│   │   ├── __init__.py
│   │   ├── app.py           # Маршруты FastAPI
│   │   ├── schemas.py       # Контракты запросов и ответов
│   │   ├── service.py       # Модель и обновление библиотеки в памяти
│   │   ├── settings.py      # Переменные окружения
│   │   └── uploads.py       # Фоновые задачи и оригиналы файлов
│   └── ui/
│       ├── __init__.py
│       ├── app.py           # Поиск, загрузка и прогресс Streamlit
│       └── client.py        # HTTP-клиент API
├── tests/

│   └── integration/         # API, UI, загрузки и настоящая модель

├── .gitattributes
├── .gitignore
├── .python-version
├── pyproject.toml
├── uv.lock

Содержимое `data/raw` и `data/processed`, кэши, секреты, веса и `.venv`
исключены из Git. Пустые каталоги сохраняются через `.gitkeep`.
